Thư mục chiếm chỗ

Ô càng to thì càng chiếm nhiều dung lượng. Bấm vào một thư mục để xem bên trong.

File lớn nhất

Đánh dấu những file anh/chị không cần nữa rồi bấm Dọn. File của hệ thống có biểu tượng 🔒 và không thể chọn.

File cũ lâu không dùng

File lớn đã lâu không được sửa. Thường là video, bộ cài đặt, bản sao lưu cũ có thể dọn.

Dung lượng theo loại file

Video, ảnh, tài liệu… mỗi loại đang chiếm bao nhiêu chỗ.

File trùng lặp

Tìm các file giống nhau hoàn toàn về nội dung (dù khác tên). Mỗi nhóm luôn giữ lại ít nhất một bản.

Khu cách ly & hoàn tác

Khi dọn, file chưa bị xóa ngay mà được cất vào đây. Bấm Lấy lại để trả file về đúng chỗ cũ. Khi đã chắc chắn không cần nữa, bấm Xóa vĩnh viễn để giải phóng dung lượng thật sự.
